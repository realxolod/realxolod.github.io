# Design Rules — Minimal Indie (rauno.me / paco.me vibe)
- **Style:** Relaxed, ultra-minimal personal site written in first person. No fake telemetry, no boxes-in-boxes, no decorative labels.
- **Layout:** Single narrow centered column (`max-width: 600px`), lots of whitespace, left-aligned.
- **Palette:** Matte dark background `#0C0C0E` (no dot grid). Text: `zinc-100` headings, `zinc-400/500` body. Hairline dividers `zinc-800/80`. Tiny accents only: emerald (live status), amber (in-progress).
- **Typography:** `Inter` for text, `JetBrains Mono` for clock, stack labels and small meta.
- **Interactions:** Live Ostrava clock, optional Web Audio micro-click sounds (toggle), generative lo-fi player, pixel filter toy (Normal / Grayscale / Box Blur).
- **Bans:** Blue-purple gradients, heavy shadows, skill percentage bars, contact forms, stock images, marketing copy.
