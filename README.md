# realxolod.github.io

Minimalist personal portfolio built with Astro and Tailwind CSS.

## Stack

- Astro (static output)
- Tailwind CSS
- TypeScript
- HTML5 Canvas & Web Audio API

## Local development

```bash
npm install
npm run dev
```

Build for production:

```bash
npm run build
```

## Shortcuts

- `L` — switch language (`EN` / `CZ` / `RU`)
- `M` — play / pause audio preview
- `Esc` — close drawer or active mode
